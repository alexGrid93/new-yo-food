# ТЗ: отметка «съедено» в личном меню

**Версия:** 1.0 (черновик)
**Источник:** баг-репорт от 31.10.2026 — пользователь просит добавить галочки, чтобы отмечать какую еду он уже съел в течение дня.

## Контекст

YoFood — фронтенд-only Vue 3 PWA, без бэкенда и аккаунтов. Всё состояние живёт в
`localStorage` ([src/enums/LocalStorageKey.ts](../../src/enums/LocalStorageKey.ts)).
Сотрудник выбирает себя один раз через `SelectEmployee`
([src/components/SelectEmployee.vue](../../src/components/SelectEmployee.vue)), после
чего `MainPage.vue` показывает его меню на день через `DishesByEmployee.vue`.

Структура меню: `MenuData[день][имяСотрудника] = string[]` — массив блюд сотрудника на
день ([src/utils/types.ts](../../src/utils/types.ts),
[src/utils/getEmployeeMenuByDay.ts](../../src/utils/getEmployeeMenuByDay.ts)). Категория
не отдельный уровень структуры — она закодирована эмодзи-префиксом внутри строки блюда.

**Побочная проблема, вскрытая при анализе:** `SELECTED_EMPLOYEE` сейчас используется и
как «кто я», и как «чьё меню я сейчас смотрю» — один и тот же ключ localStorage
перезаписывается при любом выборе в `SelectEmployee`, в т.ч. при просмотре меню коллеги.
Это нужно развести, иначе отметки «съедено» будут путаться между своим и чужим меню.

## 1. Идентичность пользователя

- Новый ключ `MY_EMPLOYEE_NAME` в `LocalStorageKey.ts`, отдельный от `SELECTED_EMPLOYEE`.
- **Онбординг-модалка**: показывается один раз, после того как меню уже загружено и
  `MY_EMPLOYEE_NAME` не задан. Выбор имени из того же списка, что строится для
  `employeesToSelect` ([src/views/MainPage.vue](../../src/views/MainPage.vue)).
- **Миграция для текущих пользователей**: если `SELECTED_EMPLOYEE` уже есть в
  localStorage, а `MY_EMPLOYEE_NAME` нет — модалка не показывается, `MY_EMPLOYEE_NAME`
  заполняется значением `SELECTED_EMPLOYEE` автоматически.
- **Смена личности**: пункт в
  [src/views/MainSettingPage.vue](../../src/views/MainSettingPage.vue), повторно
  открывающий тот же пикер и перезаписывающий `MY_EMPLOYEE_NAME`.
- **Имя не найдено в меню текущей недели**: меню показывается как раньше (без краша),
  сверху — предупреждение (Alert), предлагающее подтвердить/обновить своё имя.

## 2. Отметка «съедено»

- Новый ключ `EATEN_DISHES`: `Record<день, Record<имяСотрудника, boolean[]>>`. Индекс
  массива совпадает с индексом блюда в `menu[день][сотрудник]`.
- Хранится отдельно от `MENU_DATA`, чтобы обновление таблицы (перезалив
  Excel/Google Sheet) не затирало отметки, если состав дня не поменялся.
- Только текущий день — истории/статистики в этой версии нет.

## 3. UI

- Чекбокс добавляется в
  [src/components/DishesByEmployee.vue](../../src/components/DishesByEmployee.vue) к
  каждому `ListItem`.
- **Видимость**: чекбоксы рендерятся только когда `selectedEmployee === MY_EMPLOYEE_NAME`
  (т.е. пользователь смотрит своё меню). При просмотре меню коллеги блок чекбоксов
  полностью скрыт.
- Отмеченное блюдо — зачёркнутый текст.

## Вне скоупа (v1)

- Синхронизация между устройствами (нет бэкенда/аккаунтов — осознанное ограничение).
- История/статистика съеденного, подсчёт КБЖУ съеденного.
- Общий девайс на несколько человек.

## Acceptance criteria

- [ ] При первом открытии приложения (после того как меню загружено) новому пользователю
      показывается модалка выбора своего имени; выбор сохраняется в `MY_EMPLOYEE_NAME`.
- [ ] У существующих пользователей (есть `SELECTED_EMPLOYEE`) модалка не показывается,
      `MY_EMPLOYEE_NAME` проставляется автоматически.
- [ ] В `MainSettingPage.vue` есть возможность сменить свою личность повторно.
- [ ] В личном меню («By name», `selectedEmployee === MY_EMPLOYEE_NAME`) у каждого блюда
      есть чекбокс «съедено», состояние сохраняется в `EATEN_DISHES` и переживает reload
      страницы.
- [ ] При просмотре меню другого сотрудника чекбоксы не отображаются.
- [ ] Если `MY_EMPLOYEE_NAME` не найден в меню текущей недели — меню показывается,
      наверху отображается предупреждение.
- [ ] Отметки «съедено» не сбрасываются при обновлении таблицы, если состав блюд на день
      не изменился.
